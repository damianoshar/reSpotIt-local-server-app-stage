reSpotIt

Self-hosted Spotify library server with web UI.

Download Desktop App Source Code

Features

FastAPI backend + React frontend. Browse saved albums, filter, sort, manage playlists, sync library, export CSV. Runs via Docker or as a Windows desktop app.

Quick Start (Docker)

cp .env.example .env (fill in Spotify credentials)
docker compose up -d --build
Frontend: http://127.0.0.1:8888 | API: http://127.0.0.1:8000

Desktop App

Download the Windows executable from the releases page. Data is stored in %APPDATA%\reSpotIt\data.
